# reaction-format

Automated editing for the reaction short-form video format (hook over a freeze frame, background-removed
pen-twirl reaction cam, the creator's CTA swapped for mine, with "Comment "Word" for the full guide" text).

Also the "clipping reaction" batch format (`scripts/make_clipping_reaction.py`): every reaction clip x
every outfit, followed by an intro clip and the streamer demo.

Start a Claude Code session with this repo selected and say "make a reaction video". `CLAUDE.md` has the
full spec and workflow. `setup.sh` installs the tools.

Font: TikTok Sans, SIL Open Font License (see `fonts/TikTokSans-OFL.txt`).
